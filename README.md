# Rooks of Honor — Website

Static HTML/CSS/JavaScript site ready for GitHub Pages.

## GitHub Pages
1. Create a public repository (for example, `rooks-of-honor`).
2. Upload the contents of this folder to the repository root.
3. Make sure `index.html` is directly in the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`, then save.

All internal page links use hyphenated filenames and are relative, so the site works from a GitHub Pages project URL.
